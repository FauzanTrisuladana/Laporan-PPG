\section{Tujuan Praktikum}
\begin{enumerate}[label=\arabic*.]
  \item Mampu memahami alur penelusuran, perolehan, dan integrasi aset lingkungan 3D eksternal melalui ekosistem FAB Marketplace pada Unreal Engine 5.
  \item Mampu mengonfigurasi dan mengaplikasikan \textit{Auto-Material} menggunakan \textit{Material Instance} \texttt{MI\_landscape\_pro\_v2\_inst} pada aktor lanskap.
  \item Mampu memahami dan mengoperasikan fitur \textit{Auto-Fill Target Layer Assets} untuk penugasan berkas \textit{Layer Info} lanskap secara otomatis pada mode \textit{Paint}.
  \item Mampu menguasai teknik penataan vegetasi lingkungan permainan melalui metode \textit{drag-and-drop} manual maupun penyebaran prosedural berskala besar menggunakan \textit{Foliage Mode}.
  \item Mampu merancang hierarki antarmuka visual \textit{Heads-Up Display} HUD secara modular berbasis \textit{Widget Blueprint} \texttt{WBP\_HUD} dan \texttt{WBP\_Health}.
  \item Mampu mengonfigurasi komponen \textit{Progress Bar} sebagai indikator visual HP serta merancang animasi dinamis pada \textit{UMG Animation Timeline} Sequencer.
  \item Mampu merancang serta mengimplementasikan arsitektur komunikasi sistem yang \textit{decoupled} menggunakan \textit{Blueprint Interface} \texttt{BPI\_HUD} dan \texttt{BPI\_Widget}.
  \item Mampu mengintegrasikan siklus hidup antarmuka pengguna memakai \texttt{BP\_GameInstance} dan inisialisasi pada \texttt{BP\_ThirdPersonPlayerController}.
  \item Mampu menghubungkan \textit{Event TakeDamage} pada aktor \texttt{BP\_ThirdPersonCharacter} dengan pembaruan nilai persentase bar serta pemicu animasi saat \textit{runtime}.
\end{enumerate}

\section{Dokumentasi Praktikum}

\par Bagian dokumentasi ini menyajikan rangkaian tahapan teknis yang saya laksanakan secara komprehensif selama sesi Praktikum Pengembangan Game Pertemuan 7 dengan topik \textit{Asset FAB dan Widget Blueprint (UI)} pada Unreal Engine 5. Rangkaian aktivitas dimulai dari penelusuran pustaka aset lingkungan terintegrasi pada ekosistem FAB Marketplace, penyiapan proyek hasil salinan asisten praktikum \texttt{PPG\_2026} akibat relokasi ruang laboratorium komputer, implementasi material lanskap otomatis berbasis elevasi dan kemiringan lereng, penugasan layer tekstur secara otomatis via fitur \textit{Auto-Fill Target Layer Assets}, penempatan vegetasi pohon menggunakan metode manual maupun kuas massal \textit{Foliage Mode}, perancangan antarmuka HUD dan bar kesehatan \texttt{WBP\_Health}, perancangan animasi transformasi getar pada Sequencer, penyusunan komunikasi modular berbasis \textit{Blueprint Interface} \texttt{BPI\_HUD} dan \texttt{BPI\_Widget} yang didukung \texttt{BP\_GameInstance}, hingga integrasi masukan damage karakter pada \texttt{BP\_ThirdPersonCharacter} serta pengujian simulasi \textit{Play-in-Editor} (PIE) untuk memvalidasi responsivitas antarmuka visual secara interaktif.

\subsection{Eksplorasi Aset FAB dan Penyiapan Proyek PPG 2026}

\par Pada tahapan awal praktikum, fokus kegiatan saya arahkan pada penelusuran dan persiapan aset lingkungan fotorealistis berkualitas tinggi. Berbeda dari sesi-sesi sebelumnya, pelaksanaan praktikum ini secara teknis tidak melanjutkan berkas proyek lokal minggu lalu karena adanya perpindahan ruang laboratorium komputer. Oleh karena itu, saya menyalin repositori proyek dasar yang telah disiapkan oleh asisten praktikum dengan nama folder \texttt{PPG\_2026}. Proyek tersebut telah menyertakan paket aset \textit{Landscape Pro 2.0 Auto-Generated Material} secara lengkap, sehingga proses pada pasar aset digital FAB difokuskan pada pemahaman alur kerja pencarian dan penambahan aset ke pustaka akun pribadi tanpa perlu melakukan proses pengunduhan atau instalasi ulang yang berulang ke direktori lokal komputer.

\subsection{Konfigurasi Auto-Material dan Penugasan Layer Lanskap Otomatis}

\par Setelah memeriksa kelengkapan aset vegetasi pada proyek, langkah berikutnya adalah menerapkan material lanskap tingkat lanjut. Pengecatan lanskap standar umumnya membutuhkan proses manual yang memakan waktu lama. Melalui paket \textit{Landscape Pro 2.0}, permukaan lanskap dikonfigurasi prosedural menggunakan \textit{Auto-Material}, di mana tekstur rumput, tanah datar, dan tebing batu dipetakan otomatis oleh engine berdasarkan elevasi serta sudut kemiringan \textit{slope} geometri medan secara matematis.

\begin{figure}[H]

Pada kategori pengaturan \textit{Landscape}, saya menemukan slot properti \textit{Landscape Material}. Saya mengeklik kolom tersebut lalu menugaskan aset \textit{Material Instance} bernama \texttt{MI\_landscape\_pro\_v2\_inst}. Begitu aset dipilih, sistem Unreal Engine langsung memicu proses kompilasi shader material di latar belakang untuk menghitung parameter pencahayaan dan blending tekstur PBR.

\subsection{Implementasi Vegetasi Melalui Manual Placement dan Foliage Mode}

\par Setelah topografi dan material medan lanskap terbentuk secara solid, tahapan berikutnya adalah memperkaya ekosistem dunia game dengan menambahkan elemen \textit{foliage}. Pada praktikum ini, saya mempraktikkan dan membandingkan dua pendekatan implementasi vegetasi pada Unreal Engine 5: pendekatan \textit{Manual Actor Placement} serta pendekatan instansi grafis massal \textit{Foliage Instanced Meshes}.

\begin{figure}[H]
  \centering
  \includegraphics[width=0.8\textwidth]{resource/Dokumentasi/14.png}
  \caption{Pemilihan Aset Static Mesh SM\_dead-tree04 pada Folder Foliage}
  \label{fig:select-manual-tree-mesh}
\end{figure}

\subsection{Penyusunan Komunikasi Antar-Blueprint Menggunakan Blueprint Interface}

\par Setelah komponen bar kesehatan \texttt{WBP\_Health} beserta animasinya selesai dibangun, tahapan krusial berikutnya adalah menyusun arsitektur komunikasi data. Dalam rekayasa perangkat lunak game modern, menghubungkan karakter dengan antarmuka layar menggunakan metode konvensional seperti \textit{Direct Casting} sangat tidak direkomendasikan karena menciptakan keterikatan dependensi \textit{tight coupling}. Solusi terbaik yang diajarkan pada praktikum ini adalah memanfaatkan \textit{Blueprint Interface} BPI, di mana pesan pembaruan data dapat disalurkan secara aman dan independen tanpa mengharuskan aktor pengirim mengetahui struktur internal dari aktor penerima.

\begin{figure}[H]

\section{Hasil Akhir}

\par Berdasarkan seluruh rangkaian perancangan, implementasi, dan pengujian teknis yang telah saya laksanakan pada Praktikum Pengembangan Game Pertemuan 7 dengan topik bahasan \textit{Asset FAB dan Widget Blueprint (UI)} pada Unreal Engine 5, berikut adalah kesimpulan dan analisis komprehensif atas pencapaian hasil praktikum:
\begin{enumerate}[label=\alph*.]
  \item \textbf{Integrasi Aset Lingkungan FAB dan Preservasi Proyek PPG\_2026:} Saya telah berhasil memahami alur penelusuran pustaka aset melalui ekosistem FAB Marketplace dan menguasai adaptasi proyek salinan asisten \texttt{PPG\_2026} akibat perpindahan lab. Keberadaan paket \textit{Landscape Pro 2.0 Auto-Generated Material} yang telah tersemat dieksplorasi secara mendalam tanpa unduhan ulang, mencakup pemilahan 84 aset vegetasi dengan filter \textit{Static Mesh} dan pengujian LOD pada \textit{Static Mesh Editor}.
  \item \textbf{Efisiensi Prosedural Auto-Material dan Auto-Fill Target Layer:} Penerapan \textit{Material Instance} \texttt{MI\_landscape\_pro\_v2\_inst} pada aktor lanskap membuktikan keunggulan teknik medan modern Unreal Engine 5. Material mampu memetakan tekstur tanah datar dan tebing batuan secara otomatis berdasarkan kemiringan \textit{slope} geometri 3D. Selain itu, fitur \textit{Auto-Fill Target Layer Assets} pada mode \textit{Paint} menugaskan berkas \textit{Layer Info} seperti \texttt{Layer\_1\_LayerInfo}, \texttt{Layer\_2\_LayerInfo}, dan seterusnya secara instan tanpa konfigurasi manual.
  \item \textbf{Fleksibilitas Penataan Vegetasi Hibrida Manual dan Foliage Tool:} Saya berhasil mempraktikkan dan membandingkan dua metode penempatan vegetasi lingkungan 3D. Penempatan manual \texttt{SM\_dead-tree04} terbukti sangat presisi untuk aset penanda khusus \textit{landmark hero asset}, sedangkan pemanfaatan \textit{Foliage Mode} dengan kuas \textit{multi-selection} dan densitas \texttt{0.05} mampu menghutankan perbukitan secara masif dan fotorealistis di bawah pengelolaan aktor \texttt{InstancedFoliageActor2} yang sangat hemat memori GPU.
  \item \textbf{Arsitektur Antarmuka Pengguna Modular Berbasis UMG dan Timeline Animasi:} Perancangan antarmuka visual dibuat modular dengan memisahkan komponen \texttt{WBP\_Health} dari kanvas \texttt{WBP\_HUD}. Komponen \textit{Progress Bar} disetel berwarna hijau cerah dan dianimasikan via trek \textit{Transform} Sequencer pada koordinat $Y = -50.0$ serta $X = 100.0$ guna menghadirkan efek getaran visual saat menerima serangan.
  \item \textbf{Keandalan Komunikasi Terisolasi via Blueprint Interface dan Game Instance:} Arsitektur komunikasi berbasis \textit{Blueprint Interface} \texttt{BPI\_HUD} dan \texttt{BPI\_Widget} sukses meniadakan keterikatan langsung \textit{hard reference casting}. Penyimpanan referensi di variabel \texttt{AddedWidget} pada \texttt{BP\_GameInstance} menjamin antarmuka persisten, diinisialisasi oleh \texttt{BP\_ThirdPersonPlayerController} melalui node \textit{Add to Player Screen}, serta diperbarui oleh \texttt{BP\_ThirdPersonCharacter} saat \textit{Event TakeDamage} aktif.
